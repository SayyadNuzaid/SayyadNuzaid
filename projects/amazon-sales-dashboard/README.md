- YTD Sales
- QTD Sales
- YTD Products Sold
- YTD Reviews

## Analysis
- Product category
- Product description
- Price
- Month
- Quarter
- Week

## Data Model
- Amazon_Data
- Date Table

## Tools

- Business reporting
