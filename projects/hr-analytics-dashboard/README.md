# HR Analytics Dashboard

A Power BI dashboard for analyzing workforce, attrition and employee satisfaction.

## Business Objective

Provide a structured view of workforce composition, employee attrition and satisfaction across key HR dimensions.

## Key Metrics

- Active Employees
- Employee Count
- Attrition Count
- Attrition Rate

## Analysis Areas

- Department
- Job Role
- Age Band
- Gender
- Education
- Education Field
- Job Satisfaction

## Data Model

- Sheet1

## Tools

- Power BI
- HR analytics
- Data modeling
